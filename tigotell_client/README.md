# tigotell-client

Async Python client for the REST API exposed by [gongloo/TigoTell](https://github.com/gongloo/TigoTell).

This package is intended to be published to PyPI and consumed by the Home Assistant TigoTell integration.

## Credits

TigoTell is the upstream firmware/project by gongloo. This library consumes its `/json` API; it does not replace or modify TigoTell.
